## Fase 1: Fine-Tuning de VGG16 (chinelos x tênis)

Projeto da disciplina Machine Learning II (PUCRS). Fine-tuning de uma
VGG16 pré-treinada na ImageNet para classificação binária de imagens
entre chinelos e tênis, dataset coletado manualmente.

### Como rodar
1. `python -m venv .venv` e ativar
2. `pip install -r requirements.txt`
3. Abrir `notebooks/fase1_finetuning_vgg16.ipynb` no VS Code e
   selecionar o kernel `Fase 1 - VGG16`
4. Rodar as células em ordem
